# Student Performance Data Analysis

## Objective
Analyze student performance data using Pandas and visualize insights using Matplotlib.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
Student Performance Dataset

## Analysis Performed
- Loaded CSV data
- Calculated average math score
- Generated bar chart
- Generated scatter plot
- Generated heatmap

## Visualizations
1. Average Math Score by Gender
2. Reading Score vs Writing Score
3. Correlation Heatmap

## Observations
- Average math score was calculated successfully.
- Reading and writing scores show a positive correlation.
- Student performance patterns can be visualized effectively using graphs.
